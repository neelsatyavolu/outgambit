# Gambit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public site where visitors play timed chess against owner-connected AI models, within daily limits, while the owner watches.

**Architecture:** Next.js App Router on Vercel. All game rules, clocks and limits live in pure `lib/` modules that take a `Db` and a `now` value, so they run unchanged against Neon in production and PGlite in tests. Route handlers are thin: validate, call `lib/`, wrap the result. Browsers poll game state once a second.

**Tech Stack:** Next.js 16.4, React 19.3, TypeScript 5, pnpm, `chess.js` 1.4, `react-chessboard` 5.12, `@neondatabase/serverless` 1.2, `@electric-sql/pglite` 0.5 (tests and local dev), `zod` 4, `vitest` 5, `@playwright/test` 1.64, `@neelsatyavolu/shared-ai-auth` (GitHub, commit `31ac039`).

**Spec:** `docs/superpowers/specs/2026-10-09-gambit-design.md`

**Plan format note:** the owner asked for implementation directly and the same session executes this plan, so tasks give files, exact interfaces and the tests to write, not full code listings.

## Global Constraints

- Limits: 2 games per player per day (cookie), 4 per IP hash per day, 10 globally per day. Aborted games do not count. One active game per player.
- Day boundary: midnight `America/Los_Angeles`.
- Time controls: LLMs `10+10`, `20+20`, `45+30`; Jev additionally `1+0`, `2+1`, `3+0`, `5+0`.
- AI illegal move: two retries, third failure forfeits. Provider error: one retry, then abort and return the slot.
- LLM per-call timeout: `min(remaining AI clock, 240_000 ms)`. Jev: 3000 ms.
- AI turn display: move only. No commentary is requested from or shown for any model.
- API envelope: `{ success: boolean, data?: T, error?: string }`.
- Secrets: AES-256-GCM with `SECRETS_KEY`. Tokens, keys, auth codes and callback URLs are never logged or returned to browsers.
- Environment: `DATABASE_URL`, `OWNER_PASSWORD`, `SECRETS_KEY`, `IP_SALT`; missing values fail fast.
- Design: `~/DESIGN.md` (Machine & Ink): tokens from its section 9, Geist Mono / Geist / Newsreader, 0 radius, no shadows, one blue accent.
- Code style: no input mutation, files under 400 lines, functions under 50, no `console.log`.
- Before writing Next.js code, read the relevant guide in `node_modules/next/dist/docs/` (Next 16 differs from older versions).

## Review Focus

1. **Model replies wrapped in prose or markdown** (`**Nf3**`, `1... e5`, `I'll play e2e4.`): the move is still found; a reply naming two different legal moves is `invalid`. Test in Task 2 (`parse-reply`).
2. **Player submits the same move twice** (double click, two tabs): the second request is rejected and the clock is charged once. Test in Task 6 (`move`).
3. **Two polls arrive at lease expiry**: exactly one restarts the AI turn. Test in Task 6 (`ai-turn` lease claim).
4. **Game created at 23:59 Pacific, and across a DST change**: it counts toward the day it was created, and `resetAt` is the next Pacific midnight. Test in Task 6 (`limits`).
5. **Pasted OAuth callback that is garbage, has the wrong state, or arrives after the PKCE cookie expired**: a clear error, nothing stored. Test in Task 4 (`oauth`).

## Shared Types

```ts
// lib/db/client.ts
type Queryable = { query<T = Record<string, unknown>>(sql: string, params?: unknown[]): Promise<T[]> };
type Db = Queryable & { transaction<T>(fn: (tx: Queryable) => Promise<T>): Promise<T> };

// lib/game/types.ts
type Provider = "codex" | "grok" | "gemini" | "openrouter" | "jev" | "fake";
type Effort = "low" | "medium" | "high";
type Color = "white" | "black";
type Status = "active" | "finished" | "aborted";
type Result = "white" | "black" | "draw";
type Reason = "checkmate" | "stalemate" | "repetition" | "fifty_move" | "insufficient_material"
            | "timeout" | "resignation" | "illegal_move" | "provider_error";
type Game = { id: string; playerId: string; ipHash: string; day: string; provider: Provider; model: string;
  modelLabel: string; effort: Effort | null; initialMs: number; incrementMs: number; playerColor: Color;
  fen: string; ply: number; whiteMs: number; blackMs: number; turnStartedAt: number;
  aiLeaseUntil: number | null; status: Status; result: Result | null; reason: Reason | null; createdAt: number };
type Move = { ply: number; san: string; uci: string; fenAfter: string; spentMs: number };

// lib/ai/types.ts
type MoveRequest = { fen: string; history: string[]; legalMoves: LegalMove[]; color: Color;
  remainingMs: number; model: string; effort?: Effort; rejected?: string; signal: AbortSignal };
type MoveResult = { kind: "move"; san: string } | { kind: "invalid"; raw: string }
                | { kind: "provider_error"; message: string };
type Adapter = (req: MoveRequest) => Promise<MoveResult>;
```
